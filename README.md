# 실시간 커뮤니티 온도

토스증권 종목 커뮤니티에서 오가는 말을 채점해 **공포지수**로 바꾸고, 같은 시간축의 봉 차트 옆에 놓는 도구입니다.

LLM을 쓰지 않습니다. 채점은 단어 사전이고, API 키도 토큰 비용도 없습니다.

```
node fetch-comments.mjs   →  data/{티커}.posts.json   글 원문 (증분, 처음만 40~60분)
node build.mjs            →  data.js                   일봉 + 채점 + 기준선 (몇 초)
node server.mjs           →  http://localhost:8731     실시간 서버
```

## 화면

한 페이지에 네 탭입니다.

| 탭 | 내용 |
|---|---|
| **실시간** | 종목 판(현재가·등락·거래량·거래대금·체결강도·곡소리, 머리글로 정렬), 1/10/60분·일봉 차트, 이동평균 20·120·200, 최근 1시간 글 |
| **분석** | 수집 기간 전체를 표로. CSV 내려받기 |
| **글** | 모아둔 글 검색·필터 (감정·기간·좋아요순) |
| **사용법** | 계산식 전부 |

봉 차트는 휠로 확대, 끌어서 이동, 더블클릭으로 초기화합니다. 공포지수 차트가 같은 격자를 쓰므로 세로선 하나로 둘을 같이 짚습니다.

## 공포지수

비율이 아니라 **개수**로 냅니다.

```
k     = 그 봉이 덮는 구간에 온 공포 글 수
μ, σ  = 그 종목 · 그 미 동부 시각 · 같은 봉 길이의 평소 공포 글 수

z          = (k − μ) / σ
공포지수    = clamp(50 + 20z, 0, 100)      50 = 평소 · 90 = 경보
```

1분봉은 글이 중앙값 2건이라 비율이 0% / 50% / 100% 셋뿐입니다. 표본 문턱을 걸면 97%가 빈칸이 됩니다. 짧은 구간에서 실제 신호는 "몇 %가 공포냐"가 아니라 "공포 글이 몇 개 쏟아졌냐"입니다.

기준선을 만들 때 두 가지를 지킵니다.

- **글이 하나도 없는 칸도 0으로 셉니다.** 빼면 평균이 부풀려집니다 (SNDK 미 동부 10시 1분봉: 포함 0.60 · 제외 1.59).
- **주말은 뺍니다.** 넣으면 평일 같은 시각이 늘 높아 보입니다 (0.60 → 0.45).

시각별 기준선이 필요한 이유는 한국 사용자가 쓰기 때문입니다. 같은 SNDK 1분봉인데 미 동부 10시(한국 23시) 0.60건, 14시(한국 새벽 3시) 0.10건입니다.

자세한 건 화면의 `사용법` 탭에 있습니다.

## 감정 점수

`lexicon.js`의 사전에 걸린 단어만 셉니다. 긍정 34개·부정 34개, 가중치 1~3.

```
s = clamp( Σ(부호 × 뒤집기 × 가중치) / (걸린단어수 × 2.2), −1, +1 )

부호     긍정 +1 · 부정 −1
뒤집기   단어 직전 4글자에 안 / 못 / 없 / 아니 가 있으면 −1
걸린 단어가 없으면 0 (중립. "부정"이 아님)
```

브라우저와 Node가 같은 `lexicon.js`를 읽습니다. 한쪽만 고치면 화면 점수와 수집 점수가 갈립니다.

## 라벨 찍기

사전은 부정을 정밀도 67%로 맞히지만 재현율이 34%입니다. 셋 중 둘을 놓칩니다.
어디서 놓치는지는 글을 직접 봐야 알 수 있어서, 글 탭에서 바로 찍습니다.

`라벨`을 켜면 글마다 **긍정·중립·부정** 세 버튼이 붙고 사전이 뭐라 했는지가 옆에 나옵니다.
어긋나면 빨갛게 표시됩니다. 글을 누르고 <kbd>1</kbd>·<kbd>2</kbd>·<kbd>3</kbd> 을 찍으면
저장되고 다음 글로 넘어갑니다. 같은 버튼을 다시 누르면 무릅니다.

보기는 네 가지입니다.

| 보기 | 쓸 자리 |
|---|---|
| **안 찍은 것** | 라벨을 모을 때. 기본값 |
| **사전과 어긋남** | 사전을 고칠 때. 여기 모인 글이 곧 고칠 목록 |
| **찍은 것** | 내가 뭘 찍었는지 되짚을 때 |
| **전부** | 거르개 없이 |

`data/labels.jsonl` 에 한 줄씩 붙습니다. 나중 줄이 이기므로 고쳐 찍어도 앞줄을 지울 필요가 없습니다.
손으로 모은 것이라 다시 만들 수 없습니다 — `data/` 는 git 에 안 들어가니 [볼륨 백업](DOCKER.md#볼륨)으로 챙기세요.

```
node tools/eval-lexicon.mjs
```

홀드아웃 12,000건과 직접 찍은 것을 따로 채점합니다. 사전을 고치고 다시 돌려 비교합니다.
직접 찍은 쪽은 어긋난 글만 골라 찍기 때문에 홀드아웃보다 낮게 나오는 것이 정상입니다.

## 서버가 필요한 이유

토스 API가 `Origin` 헤더가 붙은 요청을 거절합니다.

```
헤더 없음 (서버)              200
Origin: 아무 사이트           403
Origin: tossinvest.com       200  ACAO: https://www.tossinvest.com
```

브라우저는 교차 출처 요청에 `Origin`을 반드시 붙이고 JS로 바꿀 수 없습니다. 그래서 정적 호스팅(GitHub Pages 등)만으로는 실시간·봉·글 어느 것도 못 받습니다. Node가 대신 부르고 결과만 넘깁니다.

## 접근 제한

서버를 처음 켜면 `.access-key`가 생깁니다. 링크에 `?k=` 로 붙습니다.

```
http://localhost:8731/?k=...
```

키가 없으면 **모든 경로가 404**입니다 — 있는지조차 알려주지 않습니다. 첫 요청에 키가 맞으면 쿠키를 심어 이후 요청은 파라미터 없이 통과합니다.

키가 새면 `.access-key`를 지우고 재시작하면 됩니다. 이전 링크가 전부 죽습니다.

## 한계

- **토스 내부 API입니다.** 문서화된 계약이 아니라 언제든 바뀔 수 있고, 바뀌면 수집이 오류로 죽습니다.
- **사전 채점입니다.** 반어법과 신조어를 놓칩니다. 부정어가 뒤에 오면("손절 안 했다") 놓칩니다. 다만 기준선을 같은 채점기로 계산하므로 오탐이 평균에 섞여 z에서 차감됩니다. 보는 건 절대 수준이 아니라 변화입니다.
- **개수 기반이라 글이 몰리기만 해도 오릅니다.** 그래서 툴팁에 `글 / 공포`를 같이 띄웁니다.
- **상관은 인과가 아닙니다.** 공포지수가 먼저 튀었다고 그게 주가를 예고한 건 아닙니다.
