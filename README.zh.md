把 [Toss 证券](https://www.tossinvest.com/)（韩国券商）个股社区里的发言打分，换算成
**恐慌指数**，并放在同一时间轴的 K 线图旁边。

## 与同类工具的不同

多数社交情绪工具统计的是**提及次数**或**多空比例**。这个项目衡量的是
*恐慌帖数量*有多反常 —— 基准线按「个股 × 美东时段 × K 线周期」分别建立。

```
k     = 该根 K 线时间窗内的恐慌帖数
μ, σ  = 该个股 · 该美东时段 · 该周期下平常的恐慌帖数

z      = (k − μ) / σ
恐慌指数 = clamp(50 + 20z, 0, 100)      50 = 平常 · 90 = 警报
```

用数量而不是比例，是因为：一个只有 3 条帖子、其中 80% 恐慌的版块，
和一个 400 条帖子里 30% 恐慌的版块，不是同一件事。
按时段归一化也是必要的 —— 韩国时间 23:30（纽约开盘）的版块
和早上 08:00 的版块，本来就是两个地方。

| | 做法 | 数据来源 |
|---|---|---|
| [ApeWisdom](https://apewisdom.io/wallstreetbets/) | 原始提及次数，每小时更新 | 约 30 个 subreddit |
| [SwaggyStocks](https://swaggystocks.com/dashboard/wallstreetbets/ticker-sentiment) | 关键词多空比例 | r/wallstreetbets |
| [StockTwits](https://stocktwits.com/) | 用户自己标注看涨/看跌 | 自有社区 |
| [CNN Fear & Greed](https://www.cnn.com/markets/fear-and-greed) | 7 项市场内部指标（VIX、广度、认沽认购比） | 行情数据，非发言 |
| **本项目** | **恐慌帖*数量*相对分时段基准的 z 分数** | **Toss 证券（韩国散户）** |

就目前所见，公开项目里没有以这种方式覆盖韩国券商社区的。

## 界面

单页五个标签：**看板**（可排序表格：现价、涨跌、成交量对比前日、成交额、
强度、恐慌）、**实时**（1/10/60 分钟与日 K、MA 20/120/200、恐慌指数及其 MACD、
最近一小时的帖子）、**分析**（整个采集期的表格，可导出 CSV）、
**帖子**（搜索与筛选）、**用法**（全部计算式）。

手机上双指缩放，桌面滚轮缩放，拖动平移，双击还原。
恐慌指数图与 K 线共用网格，所以一条竖线可以同时读两张图。

## 运行

```bash
node fetch-comments.mjs   # → data/{代码}.posts.json   帖子原文（增量；首次 40~60 分钟）
node build.mjs            # → data.js                  日线 + 打分 + 基准线（数秒）
node server.mjs           # → http://localhost:8731    实时服务
```

Node 24，零依赖。`node build.mjs --selftest` 可在无网络下跑 74 项检查。

**为什么必须要有服务端？** Toss 的接口会拒绝任何带 `Origin` 头的请求，
而浏览器在跨源请求时一定会带上它。所以单靠静态托管拿不到实时价、K 线或帖子。
只能由 Node 代为请求，再把结果转交给页面。

## 情绪打分

字符 n-gram 朴素贝叶斯分类器区分正面／负面／中性，训练集为 15,813 条标注 ——
大部分由 EXAONE 3.5 7.8B 标注，少部分由人工标注。
若没有 `model.json`，则退回 68 词的词典，并处理否定词翻转。
浏览器与 Node 读取同一个 `lexicon.js`，因此两边分数不会分叉。

**刻意用了两把尺。** 只用小模型自己的标注来评测，量到的只是「模仿小模型有多像」。
所以另取 240 条（P/N/X 各 80 条）隐去原标注由人工重新标注，且任何模型都不拿它训练。
在这把人工尺上，小模型自身的准确率是 68.8%。

## 局限

- **这是未公开的内部接口。** 随时可能变动，一变采集就会报错中断。
- **标准答案不是人给的。** 分类器继承了小模型的眼光，包括它看错的地方。
- **负面判得过多。** 人工尺上负面精确率 53.0%，人看作中性的帖子有近一半被判为负面。
  这是把漏判率从 65% 压到 14% 所付的代价。
- **恐慌词仍然是词典。** 反讽和新词会漏。不过基准线用的是同一个打分器，
  稳定的误判会被 z 分数抵消 —— 读的是变化，不是绝对水平。
- **基于数量，所以人多本身就会推高。** 因此提示框里同时显示「帖数 / 恐慌数」。
- **相关不是因果。** 恐慌指数先动，不代表它预告了股价。
